title = "A transition names a catalog item and the reason it was chosen"

status = "convention"

The catalog describes both implementation and editorial intent: `energy`,
`motion`, `use_when`, `avoid_when`. Those exist so that a transition is chosen
against the adjacent shots and the scene's tone, never from its name.

A shot therefore refers to a catalog id rather than describing an effect, and a
reference to an item that is not in any catalog is an error: it would render as
a cut and nobody would know a choice had been lost.

The recorded reason matters for the same purpose. A cut that carries "chapter
change should be overt" can be argued with six weeks later. A cut that carries
only `diamond-wipe` can only be re-litigated from memory, and memory is what
the production is trying to stop depending on.
