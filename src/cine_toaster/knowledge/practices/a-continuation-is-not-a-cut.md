title = "A shot carried across two generations is one shot, not a cut"
domain = "editing"
status = "convention"
enforced_by = ["continuation_unchained"]
evidence = ["SPEC-0007", "CT-0035"]

A video model generates a few seconds at a time. When an action is longer than
one generation, the shot is split: the second part starts where the first one
ended, from the same camera, and nothing should be visible at the join.

That join is not an editorial cut. Judged as one, it looks like the worst
possible cut -- the same setup, the same size, the same subject -- and the jump
check would say so. Declared as a continuation, it is judged as what it is: the
second part must open on the first part's last frame, from the same place, or
the audience sees the seam.
