+++
id = "one-height-per-character"
title = "One camera height per character, for the whole scene"
domain = "continuity"
status = "convention"
enforced_by = ["eyeline_height_flip"]
+++

If a character is seen slightly from above, they stay slightly from above until
something in the story changes it. Mixing heights on one face across a scene
reads as two different places cut together, even when everything else matches.

Height also carries meaning — standing filmed slightly from below, seated
slightly from above — so a change is a statement. Make it deliberate or do not
make it.

Heights are optional in the geometry. A scene that has not decided them is not
checked, which is correct: a finding computed from a default value is noise
dressed as a fact.
