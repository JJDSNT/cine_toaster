# The Last Signal

This is a small, fictional Cine Toaster production used to exercise the
operational project model. All project-facing content is in English.

The directory is a source template, not an application workspace. To create an
independent working copy:

```bash
toast demo ~/cine-toaster-projects/the-last-signal
toast serve ~/cine-toaster-projects/the-last-signal
```

The demo intentionally contains scenes at different stages so Overview,
Scenes, Review, and scene workspaces all have meaningful state to display.
