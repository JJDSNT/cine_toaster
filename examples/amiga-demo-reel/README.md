# Amiga Demo Reel

This is a fictional Cine Toaster production inspired by the visual energy of
classic computer demo reels: bold color bands, raster motion, geometric objects,
and playful transitions. It contains no external media or copyrighted footage.

The directory is a source template, not an application workspace. Create an
independent project with:

```bash
toast demo ~/cine-toaster-projects/amiga-demo-reel --template amiga-demo-reel
toast serve ~/cine-toaster-projects/amiga-demo-reel
```

The production intentionally has approved, review, blocked, active, and
not-started scenes. Together with The Last Signal, it provides two projects with
independent IDs and workflow state for multi-project development and tests.
