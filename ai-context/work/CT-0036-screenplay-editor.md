# What

Plan step 8: edit the screenplay in Cine Toaster, under ADR 0016 (amending
ADR 0006).

# Why

Writers change the screenplay where they see it with the shots that cover
it. CT-0021 scheduled the editor after the stack decision (ADR 0015).

# Done

- ADR 0016 (amends ADR 0006).
- `screenplay_edit.py`:
  - `screenplay_files` returns each file's text, its revision (SHA-256) and
    its line endings, and whether the screenplay is editable;
  - `edit_screenplay` writes one file:
    - only a screenplay file of the production, with the revision checked;
    - byte for byte and atomically, keeping CRLF and the BOM;
    - refused when the screenplay is generated (`screenplay_generated_by`)
      or the directory is read only;
    - emits a `screenplay.edited` event;
    - returns the impact on script findings (new and cleared).
- `GET` and `POST /api/screenplay`. The request body limit is raised for
  this endpoint only.
- A React editor at `/app/script.html`:
  - CodeMirror 6 (MIT) with Fountain highlighting from a pure, tested line
    classifier (`fountain.ts`);
  - file tabs for split screenplays;
  - an outline of sections and scenes, marked with the production scenes
    linked to each heading (occurrences counted across files);
  - Ctrl/Cmd+S; a conflict banner with reload; an impact panel;
  - a read-only mode with the reason; a warning before leaving with unsaved
    changes.
- The React app moved to `/app/`; `/canvas/` redirects there.
- The Script room links to the editor.
- `docs/screenplay-editor.md`.
- SINGULAR marks its screenplay as generated by `monta_v4.py` (commit in its
  git), so it opens read only there.

# Validation

- `tests/test_screenplay_edit.py` (8 tests):
  - only the edited bytes change; an unchanged text writes nothing;
  - a stale revision is refused and the file is untouched;
  - non-screenplay and escaping paths are refused;
  - a generated screenplay is refused;
  - CRLF and the BOM survive;
  - breaking a quoted line reports `script_anchor_missing` for SC-030;
  - HTTP open, edit and conflict.
- `frontend/tests/fountain.test.ts` (5 tests), plus the layout tests and a
  clean typecheck.
- Headless Chromium on a demo copy:
  - a line was edited and saved with Ctrl+S. Only that line changed (the
    rest of the file is byte-identical), and the impact panel showed SC-030
    P1's broken anchor;
  - a concurrent write made the next save show the conflict banner, and
    nothing was written;
  - after a normal save the cursor stayed on line 18.
- SINGULAR, served read-only:
  - four arc tabs and the read-only banner naming `monta_v4.py`;
  - the outline shows sections and numbered scenes.
- Full Python suite: 352 tests OK.
