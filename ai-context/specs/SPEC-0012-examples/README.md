# SPEC-0012 examples

Each `.yaml` here is a graph of SPEC-0012, written for an operation Cine
Toaster already has or one the roadmap asks for. `tests/test_compositing_schema.py`
validates every one against `cine_toaster.compositing.schema`; the files in
`invalid/` must each be refused with the code named in their `expect`.

These files are the authoritative form of the specification's Appendix B.
